Travel Office System ✈️

A full-stack MERN (MongoDB, Express.js, React/Vite, Node.js) web application designed to streamline travel agency operations, management, and bookings.

## Features
* **User Authentication & Authorization**: Secure login and registration utilizing JWT (JSON Web Tokens).
* **Booking Management**: Create, view, and manage travel bookings seamlessly.
* **Tour & Destination Catalog**: Browse and filter available travel packages and details.
* **RESTful API Backend**: Scalable Express server communicating with a MongoDB database.

## Tech Stack
* **Frontend**: React (Vite), Axios, CSS
* **Backend**: Node.js, Express.js
* **Database**: MongoDB (Mongoose)
* **Security**: bcryptjs for password hashing, JWT for session handling
